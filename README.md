# AgaNews

Un futur site d'actualités 100% statique où chaque article sera un fichier markdown — construit à la main, en apprenant, plutôt que généré d'un coup.

## Où en est ce dépôt

Le dépôt est volontairement vide de tout code de site pour l'instant. L'objectif : que le site soit écrit par toi, brique par brique, en comprenant chaque partie (markdown, HTML, CSS, JavaScript, DOM, `fetch`, conversion markdown → HTML...) plutôt que reçu tout fait.

## Le cours

[`apprentissage/atelier-aganews.html`](apprentissage/atelier-aganews.html) contient le parcours complet : 14 chantiers, du niveau zéro jusqu'au site fonctionnel, avec pour chacun un concept expliqué, une syntaxe de référence, un exercice concret, et un indice repliable en cas de blocage. Ouvre-le simplement dans un navigateur.

Une version en ligne (avec suivi de progression sauvegardé) est aussi disponible : https://claude.ai/artifact/9PB9gDyZmbErUk9m6sv4kT

## Comment avancer

1. Travaille dans un dossier séparé de ce dépôt (un « bac à sable ») pour t'entraîner sans crainte de te tromper.
2. Une fois un chantier maîtrisé, construis la vraie pièce correspondante ici, dans ce dépôt (`index.html`, `articles/`, `css/`, `js/`...).
3. Committe au fur et à mesure de tes avancées.
