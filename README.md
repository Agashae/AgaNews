# AgaNews
Mon espace d'articles pour les mini-projets, astuces et découvertes qui méritent une page, pas un repo entier.




## 💡 Pourquoi AgaNews ?

Créer un dépôt GitHub, c'est parfait pour un vrai projet avec du code, un historique et des versions.
Mais pour beaucoup de choses, c'est **trop** :

- un mini-projet fait en une après-midi
- une astuce de config qui m'a sauvé une heure
- une commande réseau utile à retenir
- un montage, un test ou une découverte avec quelques images

Ouvrir un repo pour ça, c'est se retrouver avec un dépôt quasi vide, un README de trois lignes et un projet perdu au milieu des autres.

**AgaNews règle ce problème** : au lieu d'un repo, je publie un **article**.
Une page claire, avec du texte, des images, des captures et des extraits de code si besoin.

## 📚 Ce qu'on y trouve

| Catégorie | Exemples |
|---|---|
| 🛠️ **Mini-projets** | petits montages, scripts rapides, tests de matériel |
| ⚡ **Astuces** | commandes utiles, configs, raccourcis, résolution de problèmes |
| 🌐 **Réseau & infra** | configurations, labs, découvertes de services |
| 🖨️ **Créations** | impressions 3D, électronique, bricolages |
| 🔍 **Découvertes** | outils, logiciels ou idées qui valent le coup |

## 🤔 Article ou repo ?

| 📰 Article AgaNews | 📦 Repo GitHub |
|---|---|
| Projet court ou ponctuel | Projet qui évolue dans le temps |
| Surtout de l'explication et des images | Beaucoup de code à versionner |
| Peu ou pas de code | Besoin d'issues, de branches, de releases |
| Une astuce ou un retour d'expérience | Projet réutilisable par d'autres |

**En résumé :** si ça se lit, c'est un article. Si ça se maintient, c'est un repo.

## 🎯 Objectifs

- Garder une trace de tout ce que je fais, même les petites choses
- Avoir un endroit où retrouver mes astuces rapidement
- Partager ce que j'apprends de façon simple et visuelle
- Garder mon GitHub propre, avec des repos qui ont un vrai contenu
