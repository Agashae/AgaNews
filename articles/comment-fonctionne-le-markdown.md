# Le markdown en cinq minutes

Le markdown a été créé pour qu'un texte brut reste agréable à lire, tout en pouvant être converti automatiquement en HTML. Voici l'essentiel.

## Les titres

On utilise le symbole `#`. Plus il y a de `#`, plus le titre est petit :

```
# Titre principal
## Sous-titre
### Sous-sous-titre
```

## Le texte

- `**gras**` donne **gras**
- `*italique*` donne *italique*
- `` `code` `` donne du `code`

## Les listes

Une liste à puces :

```
- Premier élément
- Deuxième élément
- Troisième élément
```

Une liste numérotée :

```
1. Premier élément
2. Deuxième élément
```

## Les liens et images

```
[Texte du lien](https://exemple.com)
![Texte alternatif](chemin/vers/image.jpg)
```

## Les citations

```
> Une citation s'écrit avec un chevron au début de la ligne.
```

Ce qui donne :

> Une citation s'écrit avec un chevron au début de la ligne.

## Les blocs de code

On entoure le code de trois accents graves :

<pre>```
console.log("Hello, markdown !");
```</pre>
